# Color-Coded Task Manager CLI

## Description
CLI todo manager with color-coded priorities and JSON file storage.

## Features
- Add/complete/delete tasks
- Colorized priority output
- Status/priority filtering

## Technologies
- Python 3.x (Standard Library)

## Installation
1. Clone the repository:
```bash
git clone https://github.com/MoayadAlshehry/task-manager.git
cd task-manager
```

## Usage
Run the application:
```bash
python main.py
```
